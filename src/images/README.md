# Images folder

Upload photos and logos here (**Add file → Upload files**).

Before uploading a photo of delegates:

- **Consent:** everyone identifiable must have agreed to be posted. For minors, that means a parent or guardian too.
- **No spoilers:** the photo mustn't reveal specific events, traditions, or the schedule of the week.
- **Size:** shrink it to under about 500 KB first (squoosh.app is a free tool).

To show a photo on a page, see "Adding photos" in the main README.
