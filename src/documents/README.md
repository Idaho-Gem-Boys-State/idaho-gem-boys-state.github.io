# Documents folder

Upload PDFs and Word documents here (**Add file → Upload files**).

Then list each one in **section 9 of `site-details.yaml`**, like this:

```yaml
  - title: "2028 Application Packet"
    for: posts
    link: "documents/2028-application-packet.pdf"
    note: ""
```

Use short file names with no spaces. Capital letters matter.

Before uploading anything for delegates or parents, make sure it covers **logistics only**. The week's activities, traditions, and schedule stay a surprise.
